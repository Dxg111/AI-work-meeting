## 1 项目概述

### 1.1 项目背景

远程办公与线上会议普及，会议数量激增，人工整理会议纪要效率低下、容易遗漏关键信息。本项目开发一套**企业级多用户智能会议纪要助手系统**，实现会议音视频上传、语音自动转写、大模型自动生成结构化会议纪要、纪要管理、分享与导出的完整闭环，降低企业会议纪要整理成本。

### 1.2 项目目标

1. **保留 V1 完整能力**：管理员上传会议音视频，系统调用阿里云百炼 Fun-ASR 完成语音识别 + 说话人分离；通过 LangChain 编排通义千问大模型，自动生成会议摘要、关键词、待办事项、分发言人总结，拼装为 Markdown 结构化纪要；支持发言人重命名、Markdown/PDF 导出、会议数据统计。
2. **新增企业组织能力**：支持部门划分、多用户使用；区分**超级管理员**与**普通用户**两种角色；超级管理员拥有全部后台管理权限，普通用户仅可操作自身数据。
3. **实现数据权限隔离**：普通用户只能查看、编辑自己创建的会议；同部门开启分享的会议可只读查看与导出；超级管理员可查看全企业所有部门、所有用户的数据；支持按部门维度统计。

### 1.3 技术栈约束

| 层 | 技术选型 | 说明 |
|---|---|---|
| 后端 | Python 3.10+、FastAPI、SQLAlchemy ORM | 前后端分离 RESTful API |
| AI 组件 | LangChain、langchain-openai（OpenAI 兼容模式）、通义千问 Qwen3.6-Plus | 智能纪要生成 |
| 语音识别 | 阿里云百炼 Fun-ASR 录音文件异步识别 | 支持说话人分离 |
| 前端 | Vue3 + Vite + Element Plus + Pinia + Vue-Router + Axios + ECharts + html2pdf.js | SPA 前端 |
| 数据库 | MySQL 8.0 | 业务数据存储 |
| 鉴权 | JWT 无状态令牌 | token 携带 user_id、role、dept_id |
| 文件存储 | 本地磁盘存储上传音视频、头像文件 | 可后续扩展对象存储 |

### 1.4 系统边界

1. 系统为企业**内部多用户系统**，单企业部署，非多租户 SaaS。
2. 角色固定为超级管理员、普通用户两种，暂不支持自定义角色。
3. 依赖外部第三方服务：阿里云百炼 Fun-ASR 语音接口、通义千问大模型兼容接口。
4. 音频文件存储于本地磁盘；云端 ASR 需要**公网可访问的音频 URL** 才能完成转写。

## 3 功能性需求

### 3.1 账号认证模块

**ID：M-AUTH**

1. **用户登录**：输入用户名、密码；校验通过返回 JWT token，token 内携带 `user_id`、`role`、`dept_id`；前端本地存储 token；用户名或密码错误返回明确错误提示。
2. **禁用校验**：被管理员禁用的账号禁止登录，返回提示"账号已被禁用，请联系管理员"。
3. **接口鉴权**：
   - 所有业务接口必须校验 JWT 令牌；token 缺失、失效返回 401，前端跳转登录页；
   - 后台管理接口（部门、用户管理、全局数据）增加角色校验，仅超级管理员可访问；普通用户访问返回 403。
4. **安全退出**：清空前端本地 token，跳转登录页。

### 3.2 用户与部门管理模块（新增，企业管理）

**ID：M-ORG 【仅超级管理员可见、可操作】**

#### 3.2.1 部门管理

1. **部门列表**：分页展示部门，字段含部门 ID、部门名称、部门描述、创建时间、部门下用户数量。
2. **新增部门**：填写部门名称、部门描述；部门名称**不允许重复**。
3. **编辑部门**：修改部门名称和描述。
4. **删除部门**：删除前校验，**部门下存在用户时禁止删除**，需先迁移或删除部门内用户。

#### 3.2.2 用户管理

1. **用户列表**：分页展示全部系统用户；支持按部门筛选、用户名搜索；展示用户名、昵称、角色、所属部门、账号状态（启用/禁用）、创建时间。
2. **新增用户**：填写用户名、初始密码、昵称、选择所属部门、选择角色；用户名**唯一不可重复**。
3. **编辑用户**：修改昵称、所属部门、账号启用/禁用状态；角色可调整。
4. **重置密码**：管理员可重置任意用户登录密码。
5. **约束**：超级管理员账号**不允许被禁用**；系统至少保留一个启用的超级管理员。

### 3.3 个人中心模块

**ID：M-PROFILE**

1. **个人资料修改**：修改昵称、邮箱。
2. **头像上传**：上传图片保存本地，更新头像路径；校验图片格式与大小。
3. **修改密码**：输入原密码 + 新密码，校验原密码通过后更新。
4. **查看所属部门**：展示当前用户所属部门信息。

### 3.4 会议管理模块

**ID：M-MEETING**

**权限核心规则（硬约束）：**

1. 普通用户：只能查询、编辑、删除**自己创建**的会议记录；仅可看到自己上传的会议，以及同部门中**开启分享**的会议（只读）。
2. 超级管理员：可查看系统内全部用户的会议，可编辑、删除任意用户会议。
3. 分享规则：会议开启【部门内分享】后，同部门所有普通用户可查看详情、查看纪要、导出纪要；**不能修改、删除、重命名、重新处理**他人的会议。

功能明细：

1. **会议上传**：上传音视频文件、填写会议标题；设置是否开启自动处理；设置是否开启部门内分享；后端保存文件生成公网 URL；数据库新增会议记录，`create_user_id` 记录为当前登录用户 ID，初始状态 `uploaded`。
2. **会议列表**：
   - 普通用户：展示自己创建的会议 + 本部门被分享的会议；支持标题模糊搜索、状态筛选、分页；
   - 超级管理员：展示全部用户会议；支持按用户、部门筛选，标题搜索、状态筛选、分页。
3. **会议删除**：普通用户仅允许删除自己创建的会议；超级管理员可删除任意会议；删除时**级联清理**关联的转写句子、发言人、纪要数据。
4. **会议详情**：展示会议基础信息、转写文本列表、发言人列表、AI 生成纪要全部内容；本人创建或超级管理员可触发重新处理、重命名发言人；被分享的只读会议仅可查看与导出。
5. **手动一键处理**：未开启自动处理时，会议创建人/超级管理员可手动触发完整流水线（ASR 转写 → 生成纪要）。
6. **修改分享设置**：会议创建人/超级管理员可开启/关闭部门内分享。

### 3.5 语音转写模块

**ID：M-ASR**

业务逻辑继承 V1，新增权限校验：**仅会议创建人或超级管理员可触发 ASR 任务**。

1. **异步提交 Fun-ASR 任务**：将公网音频 URL 提交阿里云百炼接口，开启说话人分离，获取 `task_id` 存入会议记录，会议状态变更 `transcribing`。
2. **轮询任务状态**：后端定时轮询 ASR 任务；任务成功下载转写结果 JSON；任务失败更新会议状态 `failed`，写入 `error_msg`。
3. **解析转写结果**：解析句子文本、开始时间、结束时间、speaker 说话人 ID；清空旧的转写、发言人数据后，将转写句子、发言人信息入库；会议状态更新为 `transcribed`。
4. **异常判断**：检测音频 URL 是否为本地 127.0.0.1 回环地址，直接标记失败并给出提示。

### 3.6 智能纪要生成模块

**ID：M-LLM**

前置条件：会议状态为 `transcribed`；操作权限：会议创建人或超级管理员。

1. 读取本场会议全部转写文本、发言人信息。
2. LangChain 多步链式调用大模型：
   - 步骤 1：生成全文会议摘要（300 字以内中文）；
   - 步骤 2：提取会议关键词，逗号分隔；
   - 步骤 3：提取待办事项，输出 JSON 数组（content 事项、owner 负责人、deadline 截止时间），无待办返回空数组；
   - 步骤 4：按说话人生成发言人总结 JSON。
3. **容错处理**：模型输出带 markdown 代码块需清洗；JSON 解析失败做降级处理，对应字段置空，不导致整个流程崩溃。
4. **拼装入库**：将摘要、关键词、待办、发言人总结、完整 markdown 存入纪要数据表；会议状态更新 `done`。

### 3.7 发言人管理模块

**ID：M-SPEAKER**

1. 展示本场会议所有发言人原始 ID 与显示名称。
2. **发言人重命名**：仅限会议创建人、超级管理员操作；被分享的只读会议**禁止修改**发言人名称。
3. 保存后数据库更新 `speaker_name`，页面中转写文本、发言人总结同步展示修改后的名称。

### 3.8 纪要导出与分享模块（新增）

**ID：M-EXPORT**

1. **Markdown 导出**：后端返回完整 markdown 文本，浏览器下载 `.md` 文件。
2. **PDF 导出**：前端使用 html2pdf.js 渲染页面内容导出 PDF 文件。
3. **权限规则**：
   - 会议创建人、超级管理员：无条件导出；
   - 同部门且开启分享的会议：同部门用户可导出；
   - 其他情况：无导出权限，返回 403。

### 3.9 数据统计首页模块

**ID：M-STAT**

1. **超级管理员全局统计**：
   - 卡片：全部会议总数、已完成数、处理中数、失败数；企业累计音频时长；
   - 图表：ECharts 会议状态分布饼图；近 7 天新增会议柱状图；按部门统计会议数量图表。
2. **普通用户个人统计**：
   - 卡片：我上传的会议总数、已完成数、处理中数、失败数；个人累计音频时长；
   - 图表：个人会议状态分布饼图；本人近 7 天上传会议柱状图。
3. 普通用户**看不到**全企业、其他部门数据。

## 4 非功能性需求

### 4.1 性能需求

1. 文件上传接口快速响应；ASR、LLM 等耗时任务使用**后台异步任务**执行，不阻塞 HTTP 接口返回。
2. 前端对处理中会议轮询状态，轮询间隔 5 秒，避免频繁请求。
3. 用户列表、会议列表必须分页；数据库建立部门、用户、会议相关索引，保证筛选查询性能。

### 4.2 可用性与异常处理

1. 每个业务失败场景记录 `error_msg` 错误信息，前端直接展示错误原因，无需查看服务器日志定位。
2. 会议状态机严格流转：`uploaded → transcribing → transcribed → summarizing → done / failed`；处理中状态禁用重复提交按钮。
3. 第三方接口（ASR、LLM）调用超时或异常时捕获异常，更新会议状态为 `failed`，记录错误信息。
4. 权限越界访问（普通用户尝试修改他人会议）返回 403，提示"无权限操作该会议"。

### 4.3 安全性需求

1. 所有业务接口必须鉴权；后台管理接口角色双重校验，仅超级管理员可访问。
2. **数据权限隔离**：数据库查询层自动增加过滤条件，普通用户查询会议自动过滤非本人且未分享的数据，防止越权读取。
3. 文件上传校验文件类型、限制文件大小，禁止上传脚本文件。
4. 密码统一使用 **bcrypt 加盐哈希**存储，禁止 MD5。
5. API 密钥不硬编码在代码中，全部放入环境变量/配置文件，禁止输出到日志。
6. 部署环境必须开启 HTTPS，防止 token 泄露。

### 4.4 可维护性需求

1. 项目分层：api 路由层、models 数据库模型层、schemas 数据模型层、services 业务服务层；AI 能力封装为独立服务类；组织管理封装为 `org_service`。
2. 权限逻辑封装为公共依赖（Depends），所有接口复用权限校验，避免散落。
3. 全部配置外置；更换 ASR 服务商、LLM 模型只修改服务层，不改动上层业务。
4. API 统一返回格式，便于前后端联调。

### 4.5 兼容性需求

1. 前端适配 Chrome 等主流桌面浏览器；页面表格自适应浏览器窗口。
2. 时间统一格式：`YYYY-MM-DD HH:mm:ss`。
3. 数据库字符集 `utf8mb4`，完整支持中文与特殊符号。

## 5 核心业务流程

### 5.1 超级管理员流程

1. 超级管理员登录系统，进入管理后台首页（全局统计）。
2. 进入部门管理、用户管理模块，维护企业组织结构：新增部门、新增用户、分配部门、重置密码、启禁用账号。
3. 自己上传会议，执行转写、生成纪要、导出；也可查看全部用户会议，干预任意会议任务。
4. 查看全局、分部门统计数据。

### 5.2 普通用户标准流程

1. 使用管理员分配账号登录系统，进入个人首页（个人统计）。
2. 上传会议音视频，填写标题，设置是否开启自动处理、是否开启部门分享。
3. 后端后台异步执行 ASR 转写、LangChain 生成纪要，前端轮询状态。
4. 查看自己会议详情，重命名发言人，导出纪要。
5. 在会议列表查看本部门同事**开启分享**的会议，只读查看纪要、导出，不能修改。

### 5.3 会议处理流水线（核心状态流）

```
会议上传(uploaded)
   → 触发 Fun-ASR 转写(transcribing)
   → 转写完成，句子/发言人入库(transcribed)
   → LangChain 生成纪要(summarizing)
   → 纪要入库，完成(done)
失败任一步骤 → failed（展示 error_msg，可修复后重新执行）
```

### 5.4 异常分支

1. ASR 调用失败 / LLM 调用失败 → 会议状态置 `failed`，列表展示错误信息，可排查配置后重新执行处理。
2. 公网 URL 配置错误（本地回环地址）→ 直接标记失败并提示。
3. 越权访问 → 返回 403，前端提示无权限。

## 6 数据需求

### 6.1 数据库实体说明

数据库名：`db_meeting_minutes`，字符集 utf8mb4，共 **6 张表**。

| 表名 | 说明 | 关键字段/关系 |
|---|---|---|
| t_dept | 部门表（新增） | dept_name 唯一 |
| t_user | 用户表（由原 t_admin 升级） | role 区分 super_admin / normal_user；dept_id 关联 t_dept |
| t_meeting | 会议主表 | create_user_id 关联 t_user；share_dept 部门分享开关 |
| t_transcript | 转写句子表 | meeting_id 关联 t_meeting；speaker_id、时间戳、文本 |
| t_speaker | 发言人表 | meeting_id 关联；原始 speaker_id + 可编辑 speaker_name |
| t_minutes | 会议纪要表 | meeting_id 唯一关联；摘要、关键词、待办、发言人总结、markdown |

> 完整建表 DDL 见《db_meeting_minutes.sql》。

### 6.2 会议状态机定义

| 状态值 | 含义 |
|---|---|
| uploaded | 文件上传完成，尚未开始转写 |
| transcribing | Fun-ASR 语音转写任务执行中 |
| transcribed | 语音转写完成，可以生成纪要 |
| summarizing | 大模型生成纪要处理中 |
| done | 全部处理完成，纪要可用 |
| failed | 处理失败，查看 error_msg 定位原因 |

## 7 接口总体规范

### 7.1 通用规范

1. 接口前缀统一：`/api`
2. 鉴权请求头：`Authorization: Bearer {token}`
3. 统一返回 JSON 格式：

```json
{
  "code": 200,
  "message": "提示信息",
  "data": {}
}
```

4. 分页返回格式：

```json
{
  "list": [],
  "total": 100,
  "page": 1,
  "page_size": 10
}
```

### 7.2 接口清单（主要分组）

| 分组 | 主要接口 | 方法 | 权限 |
|---|---|---|---|
| /api/auth | 登录、退出、个人资料、修改密码、头像上传 | POST/PUT | 登录接口公开，其余登录后访问 |
| /api/org | 部门列表/新增/编辑/删除；用户列表/新增/编辑/重置密码/启禁用 | GET/POST/PUT/DELETE | 仅 super_admin，否则 403 |
| /api/meetings | 会议上传、列表、详情、删除、触发转写、生成纪要、修改分享、发言人重命名、获取 markdown | GET/POST/PUT/DELETE | 登录后访问；写操作校验创建人或 super_admin；读操作校验本人/分享/super_admin |
| /api/stats | 获取统计首页数据 | GET | 登录后访问；按角色返回全局或个人统计 |

> 权限说明：`/api/org` 下任意接口，后端校验 JWT 中 role 必须为 super_admin，否则返回 403。

## 8 部署与环境需求

### 8.1 后端环境

1. Python 3.10+，使用虚拟环境管理依赖。
2. MySQL 8.0，执行 `db_meeting_minutes.sql` 初始化库表；脚本内置超级管理员账号（初始密码 Admin@123456，生产环境必须修改）。
3. 环境变量配置项：数据库连接信息、JWT 密钥、文件上传目录、PUBLIC_BASE_URL 公网基础地址、阿里云百炼 API_KEY、ASR 模型名称、大模型 base_url、聊天模型名称。
4. 本地开发：使用 ngrok 内网穿透提供公网 HTTPS 地址，供阿里云 ASR 下载音频文件。

### 8.2 前端环境

1. Node.js 18+；执行 `npm install`；开发模式 Vite 运行；生产模式 `npm run build` 打包静态资源。
2. Vite/Nginx 配置代理，将 `/api`、`/uploads` 转发到后端 FastAPI 服务地址。
3. 前端路由权限控制：超级管理员渲染部门管理、用户管理菜单；普通用户隐藏全部组织管理菜单。

### 8.3 初始化要求

1. SQL 脚本执行后自动创建数据库、全部数据表，并插入一条超级管理员账号。
2. 首次登录后强制建议修改初始密码。

## 9 系统验收标准

### 9.1 账号与权限验收

1. 超级管理员登录后可访问部门管理、用户管理；可新增部门、新增普通用户并分配部门；可禁用普通用户，禁用后该账号无法登录。
2. 普通用户登录后看不到组织管理菜单；直接调用管理接口返回 403。
3. 普通用户访问他人未分享会议（详情、导出、修改）返回 403 或无数据。

### 9.2 数据隔离验收

1. 用户 A 上传会议，用户 B（不同部门）看不到 A 的会议。
2. A 开启部门分享后，同部门用户 B 可只读查看、导出，**不能修改、删除、重命名**。
3. 超级管理员可查看全部部门、全部用户的会议。

### 9.3 业务功能验收

1. 上传会议成功生成记录；开启自动处理，状态流转正常，最终到 done。
2. 音频完成转写，带说话人区分，时间戳、转写文本正常展示。
3. AI 纪要生成摘要、关键词、待办事项、发言人总结，markdown 格式完整可读。
4. 发言人重命名后，页面所有位置同步生效。
5. Markdown、PDF 导出文件正常下载打开。
6. 统计首页卡片数据、ECharts 图表正常渲染。

### 9.4 异常场景验收

1. 公网 URL 配置错误，会议标记 failed 并展示错误信息。
2. LLM 返回异常不会导致系统崩溃，对应字段降级为空。
3. 删除会议级联删除转写、发言人、纪要数据。
4. 删除部门时部门下存在用户则禁止删除。
