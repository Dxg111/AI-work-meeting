## 🎯 核心功能实现

### 完整流水线
```
用户上传音频 
  → 保存文件生成公网URL 
  → 创建会议记录（status=uploaded）
  → 提交 ASR 任务（status=transcribing）
  → 调度器轮询 ASR 结果
  → 解析转写文本入库（status=transcribed）
  → 自动触发 LLM 生成纪要（status=summarizing）
  → 纪要入库（status=done）
  → 前端展示完整结果
```

### 状态机
- `uploaded` → `transcribing` → `transcribed` → `summarizing` → `done` / `failed`

### 轮询机制
- **后端**：APScheduler 每10秒轮询 ASR 任务
- **前端**：处理中的会议每5秒自动刷新
